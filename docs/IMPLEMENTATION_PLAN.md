# Agrorithm implementation plan

1. Verify tools, repository access, challenge, data contracts and licenses. Preserve the supplied team logo.
2. Cache genuine POWER weather and a quality-filtered NASA vegetation subset. Build reproducible acquisition and manual imports.
3. Implement a pure, date-aware rotation screening engine, explicit constraints, historical replay, sensitivity and provenance-rich exports.
4. Build Field Studio (default), Agronomist Console and Farmer Companion over shared inputs and results. Add Urdu, accessibility and offline behavior.
5. Generate editable Blender root-zone and groundwater scenes, small GLBs and posters with licensed PBR textures; inspect exports in the application.
6. Verify calculations, production subpath, responsive layouts, failure states and navigation. Record evidence and limits.
7. Push milestone commits to a feature branch and open a review PR. Prepare manual Pages deployment without publishing or merging.

Pilot: configurable northern Punjab regional point, not an identified private farm. Crop management, soil, equipment and current rotation are explicitly demonstrative inputs pending farmer confirmation. Weather and vegetation observations remain independently identified.
