# Three interface concepts

Default: **Field Studio**. A broad editorial calendar makes multiyear sequence comparison readable without compressing uncertainty into a score. Warm cream, dark forest ink, sage and grain tones connect the interface to the cutaway. Century Gothic unifies headings, labels and controls where installed; bundled DM Sans is the licensed fallback and Instrument Serif supplies italic accents. Variable weights, sizes, spacing and tabular numerals establish hierarchy across pages.

**Agronomist Console** changes information density and structure: dark fixed evidence rail, compact quantitative hierarchy using the same shared font, tighter calendar and comparison tables, small 3D inspector. It suits evidence review and parameter checking.

**Farmer Companion** changes the interaction rhythm: guided steps with progress, single-column content, larger targets, fewer simultaneous decisions, expandable technical detail and English/Urdu navigation. Full methods remain accessible. Translation is provisional and requires fluent agricultural review.

All three consume the same React state and pure engine. They share actual workflows rather than separate mocked results. Switching concept routes preserves current in-memory inputs. The opening menu offers a normal planning-style choice; development previews are confined to `#/design`.

Review at `/FieldShift/#/design`; live desktop/mobile iframes accompany links to complete sample journeys. The screenshots in this directory are production-browser captures at 1440×1000 and 390×844. They document observed layouts, not fabricated device renders.

The menu's diorama is an editable Blender scene exported to glTF, with a poster used before loading or when WebGL fails. No unskippable introduction, hover-only navigation, audio or heavy environment-map download. Essential science labels remain HTML outside the canvas.

The separate `#/atlas` page shows a genuine historical climate grid with provisional crop-fit overlays and hypothetical soil filters. The optional opening-page sticky scroll story rotates the cutaway and separates layers. Reduced motion replaces the scroll sequence with a static block.

The current exhibition refinement is documented in [visual QA](../VISUAL_QA.md). `agrorithm/` contains actual production screenshots of the space opening, four crop category studies and two soil views, plus machine-readable bounds/label checks. The references informed typography, scale and restrained scrolling; no proprietary assets were copied. The default remains Field Studio.
