# Reference review

The public Pyroscale Explore page was inspected on 15 November 2026. Its sections include map layers, regional analysis, historical/seasonal summaries, weather context, a scenario lab and exports. Agrorithm applies those useful exploration principles to a separate farming question rather than copying the other project's design, text or assets.

Agrorithm's detail is organized into distinct pages: a searchable satellite atlas; eight sourced/provisional crop references and four shared botanical category models; shallow soil and deeper groundwater explanations; field setup; observation coverage and provenance; a 36-month aligned rotation lab; hypothetical weather/water stress tests; binding constraints; Pareto trade-offs and sensitivity; and a paginated presentation report plus JSON/CSV. The three interface concepts share state and the same numerical engine. Search and direct navigation make this depth accessible without requiring the cinematic intro.

Data detail is useful only when it supports a decision. The pilot therefore exposes observation dates, missingness, spatial support, valid HLS scene coverage, local-soil unknowns and assumptions. It does not add unsupported yield, aquifer-depth, crop-identity or calibrated success-probability claims to appear more comprehensive. No comparison here claims that either project has been independently validated scientifically.
