# Review and release — 15 November 2026

The refresh splash prepares the active page, bundled fonts, visible images and observations underneath it. Its progress counts completed tasks, with an always-available Continue action and an eight-second escape. Optional offscreen models remain lazy. Page changes use a short native view transition when supported; reduced motion removes it.

The Earth sequence spans 330 viewport heights on desktop and 290 on phones, with a damped 98-degree guided turn before the full-width historical map. The NASA VTAD clouded globe is real geometry; its lighting and Sun placement are illustrative. The flat map is the August 2004 Blue Marble composite. Neither texture represents live clouds or current conditions.

HTML model annotations now use arrowed leaders to projected geometry. Leaf anchors use actual mesh surfaces rather than empty combined bounding-box centers. Hidden, occluded and colliding annotations and their arrows disappear together; equivalent descriptions remain accessible outside the canvas. Readable content keeps at least 20-pixel side gutters, independently of full-bleed scenes/maps. The About page uses the Agrorithm logo.

Actual validation: TypeScript and ESLint passed; all 34 unit tests passed. The production browser suite passed all 29 tests in 3.2 minutes, including refresh/skip preparation, full-width opening/map, readable charts in all three concepts, keyboard navigation, state continuity, exports, geolocation fixtures, request failures, offline sample and WebGL fallback. A separate 20-case desktop/phone model/arrow/chart/layout run passed 198 assertions. Earlier broader model checks cover tablet and three scroll positions; screenshots and structured evidence are in `docs/design/agrorithm/`.

Inspection found and fixed an actual chart regression: a max-width rule constrained Recharts against its zero-width measurement wrapper. Removing that rule restored drawing; explicit chart margins now reserve room for labels. Both visible paint and label bounds were checked again. A sensitivity unit test timed out when run concurrently with GPU browser checks; the complete unchanged numerical suite passed when run alone. No numerical tolerance was relaxed.

The revised sample presentation PDF is 50 pages / 3,590,567 bytes. Every page is 1440 × 810 points (1920 × 1080 CSS pixels). All seven SVG charts passed 32-pixel internal safe-area assertions; five additional synthetic layout cases passed. Rendered page contact sheets, full-size chart pages and the paired model illustration were inspected. Century Gothic regular/bold and Instrument Serif italic are embedded in this locally generated PDF; Windows font files are not redistributed in the app. See `REPORT_EXPORT.md`.

The repository was renamed by its owner to `sspace0/Agrorithm`. The owner explicitly authorized public visibility and GitHub Pages publication. `deployment.config.json` now holds `/Agrorithm/` independently of branding; the manual workflow derives its path from the repository slug. Historic verification records retain the old `/FieldShift/` path they actually tested. Source review remains on the feature branch and PR; deployment does not merge that PR.

These are software and rendered-layout checks, not agronomic validation or physical-device GPU benchmarks. Historical replay and learned historical patterns cannot establish future yield, profit, soil-carbon improvement or groundwater change.
